# SSPL Projects Overview

The Student Space Programs Laboratory manages a dynamic portfolio of space exploration projects spanning lunar surface utilization, CubeSat orbital missions, and suborbital atmospheric research.

---

## 🚀 Current Flagship Projects

<div class="sspl-card-grid">
  <div class="sspl-card">
    <h3>🌙 NASA LunaRecycle Challenge</h3>
    <p><strong>Status:</strong> Active Finalist (Phase 2)</p>
    <p>Engineering sustainable, autonomous physical waste processing technologies for long-duration human missions on the Moon and Mars.</p>
    <a href="lunarecycle/">View Project Page &rarr;</a>
  </div>

  <div class="sspl-card">
    <h3>🔥 SMELT (NASA Big Idea Challenge 2023)</h3>
    <p><strong>Status:</strong> Advanced Hardware Testing / Research</p>
    <p>In-situ microwave plastic pyrolysis and microwave smelting/sintering of lunar ilmenite and regolith for oxygen & metal extraction.</p>
    <a href="smelt/">View Project Page &rarr;</a>
  </div>

  <div class="sspl-card">
    <h3>🎈 National Eclipse Ballooning Project (NEBP)</h3>
    <p><strong>Status:</strong> Mission Operations & Data Analysis</p>
    <p>NASA/NSF nationwide initiative deploying atmospheric balloon payloads to record environmental and radiation phenomena during solar eclipses.</p>
    <a href="nebp/">View Project Page &rarr;</a>
  </div>

  <div class="sspl-card">
    <h3>🛰️ Flight Program & CubeSats</h3>
    <p><strong>Status:</strong> Active System Development</p>
    <p>Design, integration, link budget analysis, and ground-station integration for CubeSats (e.g. OSPREY 3U) and suborbital rockets.</p>
    <a href="flight-program/">View Project Page &rarr;</a>
  </div>
</div>
